# تطبيق مرافق نظام كروت الشبكة

تطبيق Android يمرر رسائل SMS الواردة من البنوك إلى نقطة المعالجة في خادم Laravel. لا يقرأ التطبيق رسائل أوامر العملاء ولا يرسل رسائل صادرة.

## البناء والتثبيت

1. افتح هذا المجلد في Android Studio مع Android SDK 35 وJDK 17.
2. ابنِ التطبيق وثبته على هاتف Android يدعم استقبال SMS.
3. أدخل عنوان API الأساسي المنتهي بـ `/api` وسجّل الدخول بحساب النظام.
4. اسمح باستقبال SMS والإشعارات المطلوبة.
5. اضغط «تشغيل استقبال رسائل البنك» واترك إشعار الخدمة ظاهراً.
6. استخدم HTTPS بشهادة موثوقة؛ التطبيق يرفض اتصالات HTTP غير المشفرة.
7. يمكن تفعيل قفل التطبيق اختيارياً بعد إعداد بصمة أو رمز قفل الجهاز.
8. لمزامنة دفتر العملاء، اضغط زر المزامنة وامنح إذن جهات الاتصال؛ لا تُرفع الأسماء قبل طلب المزامنة يدوياً.

## نقطة التكامل

- `POST /api/companion/login`: إصدار رمز وصول للجهاز.
- `POST /api/companion/bank-sms`: تمرير اسم مرسل البنك ونص الرسالة ووقت استلامها.
- `POST /api/companion/contacts/sync`: مزامنة جهات الاتصال التي اختار المستخدم إرسالها.

تُعالج رسائل البنك وفق قواعد المحافظ المعرفة في إعدادات النظام. الرسائل غير المطابقة تُحال للمراجعة اليدوية، ولا تُعتمد كدفعات دون مبلغ موثوق مطابق للقاعدة. لا يرسل التطبيق رسائل للعملاء؛ يتطلب إرسالها تهيئة مزود رسائل منفصل في الخادم.
